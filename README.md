# NSC-SWENG

POS and Inventory Management System for Nickel Sales Center.

## Quick start

**Windows:** open `nickel-sales\` and double-click `run-demo.bat`.
The first run finds (or offers to install) a JDK and downloads JavaFX.

**macOS / Linux:** install JDK 17+, then `cd nickel-sales && ./run-demo.sh`.

Add `--gui` to see the login screen. Full setup, IntelliJ instructions and
troubleshooting: [nickel-sales/CONTRIBUTING.md](nickel-sales/CONTRIBUTING.md).
